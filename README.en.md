A personal finance application for organizing transactions, accounts, budgets, and recurring entries.

Features include dashboards, data import and export, demo access, and authentication using an HttpOnly cookie.

**Stack:** React · ASP.NET Core · Entity Framework Core · PostgreSQL  
**Infrastructure:** Vercel · Railway · Neon

A system under development for managing clients, plans, and recurring operations.

### Argos

Price monitoring that reduces the need to check product listings manually.

The first version is a Chrome extension for Mercado Livre, with local price history and notifications when a target price or significant price drop is reached. Further development includes an API and Telegram integration.

**Extension:** TypeScript · Manifest V3 · IndexedDB · Vitest  
**Backend in development:** Python · FastAPI · PostgreSQL · Telegram
